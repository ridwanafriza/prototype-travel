# Bramjono Transwisata — UI/UX

Website statis HTML, CSS, dan JavaScript untuk Bramjono Transwisata.

## Halaman
- Beranda, layanan, detail paket, booking, riwayat, profil
- About perusahaan dan informasi legalitas
- Galeri dan dokumentasi perjalanan
- Panel Admin
- Panel Superadmin

## Akses pengelola
Dari navbar pilih **Pengelola**, lalu pilih **Admin** atau **Superadmin**.

## Teknologi
- HTML5
- CSS3
- JavaScript
- Lucide Icons via CDN
- Stock photo Unsplash

## GitHub Pages
Project ini sudah menggunakan path relatif dan `.nojekyll`, sehingga dapat dipublikasikan sebagai static site melalui GitHub Pages.

Foto yang digunakan berasal dari Unsplash. Daftar sumber foto tersedia di `assets/photo-sources.txt`.
